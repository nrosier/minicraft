CLAUDE:

I replaced the placeholder `CLAUDE.md` and wrote `index.html`. I haven't opened
the game in a browser, so none of it has been run or tested.

To try it, run `python3 -m http.server 8000` in the repo and open
http://localhost:8000. A local server is safer than opening the file directly,
because some browsers block ES module imports from `file://`.

- **`CLAUDE.md`** covers the project scope, how to run it, the architecture, the
  save format and the code standards. It follows your spec and describes what's
  actually in `index.html`.
- **`index.html`** holds everything: CSS, JavaScript, and Three.js 0.160.0 from
  the jsDelivr CDN through an import map.

How the game works:
- **World:** a 32×32×32 grid of Grass, Dirt, Stone and Air. A fresh random seed
  produces the terrain on every New Game.
- **Rendering:** the whole world is one merged mesh with hidden faces removed.
  Shading is baked into vertex colors, with no textures.
- **Controls:**
  - Up/Down move forward and back.
  - Left/Right turn.
  - Q/E strafe.
  - Space jumps.
  - PageUp/PageDown look up and down.
  - Clicking the canvas turns on optional mouse look.
- **Collision:** the player is resolved against the block grid one axis at a time.
  The world's edges and floor act as walls, so you can't fall out of it.
- **Buttons:** New Game, Save to Browser, Load from Browser, Export File and
  Import File are pinned top-left, with the controls help top-right.

Persistence:
- **Save format:** JSON with the seed, player position and angles, and
  run-length-encoded blocks.
- **Autosave:** it saves to a separate key every 30 seconds and on page unload,
  and restores on page load. Your manual save is only touched by the Save and
  Load buttons.
- **Import:** it validates the file before changing any game state. A bad file
  shows an error and leaves your current world alone.
- **Export:** the file downloads as `minecraft_save.json`.

I didn't add breaking or placing blocks, since the spec didn't ask for it.
